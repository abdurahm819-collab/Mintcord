# Security Policy

## Current security status

Mintcord is an early prototype. It currently has no network messaging, no real voice calling, and no end-to-end encryption implementation. The sample call interface is a local simulation.

Do not use this prototype to transmit sensitive information.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the project maintainer privately through GitHub.

Include the affected version or commit, the impact, and steps to reproduce without exposing another person's data.

## Security goals

Future network features must use established cryptographic protocols and maintained libraries. Security claims must describe what is protected, what metadata may remain visible, and the limitations of peer-to-peer connectivity.
